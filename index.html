🧮 sum() – Smart Number Addition

Model: DeepSeek • Version 1.0

This tool provides a fast, tested sum function that adds up all numbers in an array. Import it from src/sum.js and use it anywhere in your Node.js project.

  • Sum of any numeric array
  • Works with a single value
  • Zero‑dependency, lightweight
  • ES module ready

Example:
import { sum } from "./src/sum.js";
sum([1, 2, 3]) // → 6
